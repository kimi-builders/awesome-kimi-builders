## 收录口径

**不要求 100% 由 Kimi 构建。** Kimi 参与了、为 Kimi 生态做的应用、以 Kimi 为基座的项目都算;
参与的 Agent 会在条目里标出。无论曾经多好,已废弃或停止维护的项目不予收录。
收录标准与流程见 [CONTRIBUTING.zh-CN.md](./CONTRIBUTING.zh-CN.md)。
